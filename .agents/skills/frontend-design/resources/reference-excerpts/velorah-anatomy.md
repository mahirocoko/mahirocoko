# Velorah Anatomy Excerpt

Non-canonical reference evidence. Use for anatomy and constraints only.

## Reference shape

- Single-page hero section with navigation, headline, supporting copy, CTA, and full-viewport media.
- Background media acts as atmosphere; it needs overlay/readability rules, crop focal point, poster fallback, and reduced-motion handling.
- Typography roles are explicit: display face for logo/headline, body face for nav and copy.
- Motion is simple fade/rise sequencing rather than a full interaction system.

## Keep as anatomy

- Clear nav / headline / support copy / CTA hierarchy.
- Concrete responsive headline and supporting-copy scale notes.
- Media role definition for hero background video or poster image.
- Reduced-motion and fallback requirements.

## Reject or reinterpret

- Liquid-glass navigation and CTA as a default material.
- Rounded-full CTA/nav treatment unless the brand explicitly wants a pill system.
- Hover scale as routine interaction.
- Cinematic video dominance when product clarity or accessibility needs more content density.

## Route

- Background video/poster/crop/fallback planning -> `asset-designer`.
- Single poster or background prompt -> `web-asset-prompts`.
- Final UI cleanup -> `uncodixify`.
