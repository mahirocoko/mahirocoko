# Liquid Glass Agency Anatomy Excerpt

Non-canonical reference evidence. Use for anatomy and constraints only.

## Reference shape

- Multi-section landing page decomposition with hero, proof, media, statistics, services, CTA, and footer jobs.
- High-specificity token thinking: fonts, colors, radius, material variables, media inventory, and implementation notes.
- Distinguishes subtle and strong material variants, even when the material choice itself should be rejected.

## Keep as anatomy

- Explicit section contracts and content responsibilities.
- Token inventory discipline: font roles, surface rules, radius system, media roles, fallback detail.
- Asset/media inventory for hero, start, stats, and CTA/footer sections.
- Responsive constraints and implementation detail that reduce ambiguity.

## Reject or reinterpret

- Global `9999px` radius as default.
- Liquid glass as the core visual language.
- Repeated blur/glass variants across every section.
- Luxury/editorial/dark premium framing unless that is the actual brand direction.

## Route

- Media inventory -> `asset-designer` for crop, fallback, poster, and delivery planning.
- Individual generated backgrounds or posters -> `web-asset-prompts`.
- Material/radius/interaction cleanup -> `uncodixify`.
