# Portable Handoff Excerpt

This skill-local handoff fixture is sandbox input for validation and examples. It is not prompt canon.

## Page job

Create a calm wellness landing page with a clear hero promise, one primary action, and a concise proof strip.

## Content hierarchy

1. Brand mark and compact navigation.
2. Hero headline for guided daily recovery rituals.
3. Supporting copy for busy professionals who need a simple reset practice.
4. Primary CTA: Start a 7-day reset.
5. Secondary CTA: View rituals.
6. Proof strip: 12k members, 4.8 average rating, 10-minute sessions.

## Design constraints

- Warm neutral palette with soft green accent.
- Avoid generic glassmorphism and decorative gradient blobs.
- Use one calm image or abstract background only when it improves comprehension.
- Keep motion subtle and reduced-motion safe.
