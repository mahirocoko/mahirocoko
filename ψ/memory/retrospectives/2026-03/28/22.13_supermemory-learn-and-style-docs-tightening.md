## Lessons Learned

- A deep `/learn` run is only truly done when the artifact set is complete on disk, not when background agents merely report good findings.
- For external-repo study, the most valuable synthesis is usually at the integration boundary: what the repo exposes, what it abstracts, and what is merely documented contract versus present source.
- The product-feel doctrine in Mahiro-style keeps proving useful because it blocks a common failure mode: refactors that preserve logic but quietly flatten the user experience.
