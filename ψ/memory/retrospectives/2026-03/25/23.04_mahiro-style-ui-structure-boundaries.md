But once the examples started getting tested, it became obvious that a shallow rule would do more harm than good. What felt strongest was the move toward "earned UI depth." That phrase is not just about nesting. It carries the real review question: did this layer earn its place through layout, semantics, accessibility, state, or ownership, or is it just there to make a file look smaller? Once that clicked, the rest of the wording became easier to align. ## Honest Feedback
Three friction points stood out. First, the doctrine took a couple of false starts before the vocabulary stabilized. Beginning with "HTML element restraint" was useful as a probe, but it was too narrow for the real concern. That meant some early edits had to be rewritten once it became clear that wrapper components were part of the same pattern. The rewrite was worth it, but it added churn.

Second, examples are deceptively hard. A weak example can distort the rule more than a weak sentence because it teaches a habit by implication. The first version of the simple card example did not fit Tailwind reality well enough, and the first prop-boundary example leaned too hard toward "many props bad." Both had to be rebuilt before the doctrine could be trusted.

Third, the wording needed one extra editorial pass after the logic was already correct. That is a useful reminder that good doctrine is not just true; it also has to sound stable. If the phrasing feels too jargony or too absolute, future use will drift even when the idea is right. This session improved that, but only because the polish step was treated as real work rather than optional decoration.

## Lessons Learned
- UI structure depth should be treated as earned architecture, not as a raw count of HTML nodes or component layers.
- Long prop lists are not the smell by themselves; the real smell is parent internals leaking through a boundary that did not earn its own contract.
- Doctrine examples need the same rigor as doctrine rules because one bad example can push a false habit into future reviews.
