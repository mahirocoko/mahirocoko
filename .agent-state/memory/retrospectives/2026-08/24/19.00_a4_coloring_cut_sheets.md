## Honest Feedback

มี friction สามจุดหลัก จุดแรกคือผมควรถามความหมายของ A4 และจำนวนสัตว์ตั้งแต่ต้น แทนที่จะเลือก six full-page illustrations จากสมมติฐานของตัวเอง แม้งานนั้นออกมาดีและนำกลับมาใช้ได้ แต่ยังเป็นรอบที่ไม่จำเป็นถ้า alignment ชัดตั้งแต่แรก จุดที่สองคือ Agy/Gemini consultation ถูก block ด้วย account eligibility verification ทำให้ขั้นตอน consultation ไม่ได้ให้คุณค่า แต่ผมจัดการได้ถูกทางด้วย retry เพียงครั้งเดียวแล้วรายงาน blocker ตรง ๆ แทนการวนรอ จุดที่สามคือครั้งแรกที่พยายามลบ gray fill ผมวาง threshold ก่อน alpha flatten ผลคือสัตว์หลายตัวหายจาก sheet แม้ pipeline รันสำเร็จ นี่เป็นตัวอย่างชัดว่า command success ไม่เท่ากับ visual success โชคดีที่ผมเปิด full A4 และ row crops ก่อนส่ง จึงแก้ได้ก่อน Mahiro เห็น candidate ที่เสีย กระบวนการรอบหน้าไม่ควรต้อง rediscover alpha ordering นี้อีก

## Lessons Learned

- สำหรับคำขอ printable sheet ต้องถามก่อนว่าเป็น one-art-per-page, contact sheet, card grid หรือ cutout sheet
- งานที่มี imagegen หลาย call ควรล็อก theme, count, grid, cut-guide และ style ก่อนเริ่ม generation
- สร้างสัตว์แยก call แล้วประกอบ deterministic ภายหลังให้ anatomy และ spacing เชื่อถือได้กว่าขอ provider ทำ grid ยี่สิบช่องในภาพเดียว
- Provider PNG อาจเก็บเส้นดำเป็น semi-transparent alpha; ต้อง flatten ลงพื้นขาวก่อน grayscale, threshold หรือ trim ที่พึ่งพาค่าสี
- Full-page preview อย่างเดียวอาจซ่อนรายละเอียดเสีย ต้องตรวจ row crops หรือแต่ละ cell ที่ readable scaleด้วย
- Output-safety rejection ของสัตว์ตัวเดียวไม่ควรทำให้ทิ้ง source ที่สำเร็จแล้ว ใช้ bounded replacement ที่ยังรักษาความหลากหลายและ contract เดิม
- Human visual acceptance ต้องถูกบันทึกแยกจาก mechanical image/PDF validation
