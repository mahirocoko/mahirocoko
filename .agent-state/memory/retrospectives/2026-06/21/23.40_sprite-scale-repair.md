## Lessons Learned

- Sprite generation is an asset pipeline, not just image prompting. Use `asset-designer` before multi-lane generation.
- Comparable lanes need the same base contract and only one small variation knob; otherwise judging becomes muddy.
- Evaluate sprite candidates across separate axes: identity, motion readability, scale stability, count/layout compliance, background/cutout quality, and provenance.
- When a candidate is best overall but has scale drift, stop prompting and repair locally if the issue is measurable and fixable.
- Do not hide raw generation drift with arbitrary per-frame zoom. Use shared-scale/baseline normalization and document remaining silhouette variation honestly.
