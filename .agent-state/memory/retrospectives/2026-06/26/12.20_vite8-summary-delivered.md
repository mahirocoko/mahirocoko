## Lessons Learned
- If a Vite/VitePress blog page has a “Suggest changes” source path, fetch the markdown source from GitHub rather than rendered HTML.
- For release announcements, summarize as: context, main feature, caveats, smaller features, and “what this means for us.”
- A previous process miss should not become a blocker; recover by delivering the actual user-facing answer first.
- Under high context pressure, prefer clean source extraction and concise final prose.
