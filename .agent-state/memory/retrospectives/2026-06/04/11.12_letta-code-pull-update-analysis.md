## Lessons Learned
- For tracked external repos, resolve `.agent-state`/ghq links first and treat ghq as canonical clone ownership.
- For large upstream pulls, summarize by functional theme, but ground each theme with at least a commit/file/diff check before presenting it as reality.
- Letta Code’s latest direction should be described as local-first consolidation: skills CLI, transcript-backed message search, reflection telemetry, Task* tools, terminal title config, and managed prompts are connected, not isolated changes.
- Use `bash` explicitly when running shell snippets that rely on bash word splitting or array/loop assumptions.
