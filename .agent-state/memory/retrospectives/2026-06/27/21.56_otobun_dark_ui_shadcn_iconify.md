## Key Code Changes

- Introduced a local shadcn-style foundation without using the shadcn CLI or Tailwind. This preserved direct control over a desktop dark tone while still giving the UI a consistent Button/Input/Card/Tabs/Select language.
- Added Radix Tabs and Select to replace hand-rolled tabs/selects where consistency mattered.
- Added CVA for button variants and `cn()` for class composition.
- Moved Otobun toward Murmur-like dark product tone while keeping Otobun’s own brand and logo.
- Kept actual transcription gated to Custom Model File until a real model downloader exists, preventing built-in catalog UI from pretending it can execute immediately.
- Default output path now resolves to Downloads when the user has not chosen a custom path, matching the HiroHiro-like mental model Mahiro requested.
- Quality audit removed forbidden/prototype/product-other wording and emoji UI remnants from user-facing/source scopes checked by `rg`.

## Architecture Decisions

- Do not install the full shadcn/Tailwind stack yet. Instead, use shadcn-style local primitives with Radix/CVA and custom CSS tokens. This avoids generic SaaS visual drift while solving inconsistent buttons/inputs/cards.
- Keep feature logic owned by the main agent. Gemini may be used for UI explorations, but after Mahiro’s correction, current Otobun UI ownership sits with me by default.
- Keep model catalog in constants, not inside the component. The full catalog is now a reusable product contract for future downloader work.
- Record tab remains honest setup UI until native capture is implemented. It must not imply live recording is happening.
- Output location defaults to Downloads, with custom path available through native save dialog.
