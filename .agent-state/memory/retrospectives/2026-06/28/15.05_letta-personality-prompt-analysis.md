## Lessons Learned

- Letta's personality architecture is more important than any single prompt body: `persona` defines identity, `human` defines learning lens, and temporary blocks like `onboarding` can guide setup then be deleted.
- `memo` is the Letta-native persistent identity; `tutorial` is onboarding product flow; `linus`/`kawaii` are strong voice experiments; `claude`/`codex` are compatibility behavior prompts.
- Strong upstream prompts are references, not replacements for accumulated Mahiro-specific memory.
