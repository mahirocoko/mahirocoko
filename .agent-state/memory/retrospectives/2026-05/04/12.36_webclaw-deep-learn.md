## Lessons Learned

- For `/learn --deep`, literal absolute `SOURCE_DIR` and `DOCS_DIR` paths prevent agents from writing into the cloned repo by accident.
- A local learning doc is a strong first evidence source, but install availability should still be verified against current official upstream sources before recommending a package manager command.
- MCP stdio and Docker REST are different operational models: local binary install is simpler for MCP clients, Docker is better for a service endpoint.
- Homebrew is available for `webclaw` through the official tap, not Homebrew core, so the correct command is `brew tap 0xMassi/webclaw && brew install webclaw`.
