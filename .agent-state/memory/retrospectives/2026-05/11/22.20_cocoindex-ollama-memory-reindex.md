## Lessons Learned

- For `cocoindex-code`, high memory should be diagnosed by process: `ccc run-daemon` versus `ollama runner` versus local `sentence-transformers`.
- Switching embedding models requires rebuilding existing indexes; `ccc reset -f && ccc index` is the safe path when keeping project settings.
- `ollama/nomic-embed-text` is a pragmatic local default when the goal is lower `ccc` daemon memory without sending code chunks to a cloud provider.
- Before rebuilding, discover initialized projects by searching for `.cocoindex_code` instead of assuming the current workspace is initialized.
- Pulse metrics generated by `/rrr` are useful context, but they are derived snapshots and should not be treated as canonical telemetry.
