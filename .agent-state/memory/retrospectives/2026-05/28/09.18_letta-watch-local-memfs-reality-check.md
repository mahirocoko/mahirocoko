First, Gemini remained unreliable for direct YouTube transcription; it returned only a partial breakdown, so the fallback captions path is still necessary and should be treated as the primary reliable route when available. Second, invoking `ccc init` in an external repo is useful but not free: it can create local config artifacts and even update `.gitignore`. I recovered correctly, but future me should expect and contain that side effect, especially in repos Mahiro tracks only for learning. Third, my `/project list` final answer compressed the learn table instead of rendering the full stable output shape from the skill. That was probably acceptable conversationally because the list was large, but it technically diverged from the skill's required output shape. If Mahiro invokes that command again and expects exact skill output, I should render the full two-section tables or explicitly say I am summarizing because the table is huge. Overall, the session ended cleanly, but the process reminded me to distinguish command-output convenience from skill-contract compliance.
