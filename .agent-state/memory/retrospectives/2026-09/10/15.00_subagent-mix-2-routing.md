## Honest Feedback

First, I made recommendations too early. I suggested Spark and then Luna for general-purpose work before reconstructing the evidence Mahiro explicitly cared about. That repeated the exact failure mode the routing ledger was meant to prevent. Second, my initial configuration verification was too shallow: confirming a frontmatter line was not the same as confirming the child agent's effective provider and reasoning effort. I corrected it with direct config readback and a paired launch, but only after Mahiro challenged the assumption. Third, the research fan-out was disproportionate. The detailed agents returned millions of cumulative tokens, far more than necessary for two focused routing questions. A role being available is not a reason to send it the entire historical context. I should use exact source anchors, smaller output contracts, and Main synthesis earlier. A fourth friction point was the Main model update process: I chose a supported startup route, but it opened an interactive process and an extra conversation, then resisted graceful shutdown. Next time I should establish the narrowest supported local-backend write path before launching a TUI as a configuration mechanism.

## Lessons Learned

- Model family, preset ID, provider, reasoning effort, role definition, and effective child configuration are separate claims and need separate evidence.
- In Letta 0.32.0, pass Mix 2 model presets explicitly on Agent calls until definition-only effort preservation is fixed and verified.
- Route by task class before model name: scout, researcher, implementer, advisor, verifier, specialist, and long executor should not collapse into general-purpose.
- Letta implementer is the cross-project bounded-writer default. Agy can still be first when a repo or current task deliberately selects it; never run both as writers for one scope.
- Historical telemetry must be dated by execution time, not by the later conversation that summarized it.
- Context Doctor should preserve detailed rationale when the compiled system memory is within budget; remove active contradictions before compressing useful examples.
