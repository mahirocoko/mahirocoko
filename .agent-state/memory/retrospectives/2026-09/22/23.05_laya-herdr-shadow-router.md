- Current deterministic callback/receipt rules remain authoritative.
- The no-go is scoped to `convaiinnovations/laya-typed-decisions` at the tested revision plus this custom schema and corpus; it is not a universal claim about Laya or learned routers.

## Honest Feedback

Three things created avoidable friction. First, the initial Agy implementation overclaimed “airgap” behavior and silently defaulted malformed model answers to passive decisions. Those are exactly the kinds of security-language and failure-mode shortcuts the audit was supposed to prevent, so Main should have put these invariants into the first implementation packet more explicitly. Second, I strengthened the parser after the first Agy correction but initially added tests that referenced a nonexistent helper; the immediate test failure caught it, yet this was a small unforced error caused by patching against a partially viewed test file. Reading the exact class block first would have been faster. Third, the first independent verifier arrived only after the full model run and found report-provenance gaps that required another 4 GB model load. For security-sensitive experimental harnesses, provenance metadata and choice/probability consistency should be part of the pre-run checklist, not follow-up hardening. The process still stayed safe—no real events or credentials entered the corpus, no live actions occurred, and all runtime-heavy work was serialized—but the second model run could have been avoided with a more complete evidence contract up front.

## Lessons Learned

- Structured output is not semantic consistency; independently predicted fields require explicit cross-answer invariants.
- A small model can be fast after warm-up while still being unsuitable as a supervisor because wake false negatives dominate its practical value.
- Security evidence needs provenance binding, not only a preflight boolean. Record fixture, source, manifest, revision, and model hashes in the report itself.
- “Offline flags” and “airgap” are not interchangeable. Library controls reduce accidental network use but do not create OS isolation.
- Negative experiments are worth preserving when they eliminate an attractive but unsafe architecture with real data.
