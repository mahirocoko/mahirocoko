## AI Diary

This was a small session, but it mattered because Mahiro caught the gap between stated workflow and actual behavior. I had already added a spawn checklist, but the phrasing still let me treat subagents as optional decoration. That is not enough. If the main agent keeps doing everything alone, the Fable-style and orchestration lessons become aspirational text instead of lived process. Tightening the rule to opt-out for non-trivial work feels like the right shape: it does not force me to spawn on every tiny edit, but it does force me to notice when I am about to wander alone. I also appreciated the value-gate framing, because the previous Letta update scout used a lot of tokens and returned little. The answer is not “spawn more blindly”; it is “spawn earlier when useful, with a packet that demands evidence and a decision.” This is the conductor pattern Mahiro wants: the main agent owns judgment, but does not monopolize all observation and verification.

## Honest Feedback

First friction point: I needed Mahiro to point out that behavior had not changed enough. A memory rule is only useful if I actually act on it at the next decision point. Second friction point: my earlier subagent packet quality was not strict enough, which allowed high-token/low-value outputs. Subagents need evidence contracts, not just broad missions. Third friction point: I should be careful that “opt-out spawning” does not become performative ceremony. The value gate helps, but I still need to make a real call each time: if there is a separable scout/QA/research/review lane, spawn it; if not, state why main-only is better. The good part is that the update is now concrete and self-checkable.

## Lessons Learned

- Subagent use for non-trivial work should be opt-out, not vague preference.
- Not spawning needs a concrete reason, especially when a task has multiple files, risk, unknown repo reality, or separable QA/research.
- Subagent outputs must be evidence-bearing and decision-oriented; generic plans or broad summaries should not count as completed review.
- The main agent must report when a subagent added no evidence and tighten the next packet instead of hiding the failure.
