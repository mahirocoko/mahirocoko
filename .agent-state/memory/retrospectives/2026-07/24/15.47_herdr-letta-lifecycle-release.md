## Architecture Decisions

- One interactive Letta root maps to one Herdr pane authority; headless subagents remain aggregate child evidence rather than fake panes.
- The integration is a managed external mod so Letta auto-updates cannot overwrite it.
- Herdr owns unseen root Done. Process observation may report `ended`, but never guesses child success/error.
- No prompt, task description, result, or tool output crosses the lifecycle socket.
- Pane ID is routing, not authority. Exact focus requires current PID/start/conversation identity from `agent.get` immediately before `agent.focus`.
- Engine-owned reload and ordinary cleanup are different contracts: an aborted generation is already being cleared wholesale, so repeated unregister publishes are both redundant and harmful.
- Slow local transports require semantic coalescing, not merely per-request timeouts.

## Honest Feedback

1. **I asked Mahiro to reload too many times.** Some reloads were necessary for true A/B evidence, but I changed more than one variable between a few rounds and initially treated plausible causes as likely causes. A better isolation matrix would have started with a tiny event-registration probe and tested disposal behavior before rewriting the child evidence path.
2. **My first privacy and identity claims were too broad.** Truncating a task description did not make it non-sensitive, and a validated pane-ID shape did not make persisted identity safe. I should have listed every outbound field and every stale/reuse scenario before saying those boundaries were complete.
3. **The first verification plan omitted transport backpressure and connect time.** Response size and read timeout looked bounded, but the promise queue and blocking Unix connect were not. “Bounded transport” must be checked end to end: enqueue, connect, write, read, parse, cleanup, and failure recovery. These misses did not survive release, but closing them required extra verifier cycles and another native build/install.

## Lessons Learned

- Letta mod cleanup must distinguish ordinary disposal from engine-aborted generation teardown.
- Many unregister handles can create a React external-store publish storm even when the mod itself never calls React state.
- Use `letta.signal.aborted` as the narrow reload discriminator; still stop timers/processes/sockets/panels in both paths.
- Child-process environment inheritance is not authority inheritance. Only the interactive root may own the Herdr pane.
- Privacy review must enumerate exact payload fields; bounded sensitive text is still sensitive text.
- Persisted routing IDs require fresh strong identity before action.
- A timeout claim is incomplete unless queueing and connection establishment are also bounded.
- Process disappearance supports `ended`, not success/error truth.
- When foreground debugging stalls, a read-only direct CLI consultation can be more valuable than another speculative patch.
