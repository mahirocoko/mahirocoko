## Architecture Decisions

- Human visual/product acceptance is the final gate; passing tests, build, browser interaction checks, HiroHiro evidence, or Agy's own summary cannot substitute for it.
- Reference captures are evidence for measurable decisions, not a runtime source to paste into the product.
- Agy/Gemini is an implementation/review lane, not the owner of product taste or acceptance.
- For untracked lab work, establish and preserve a baseline before a large rewrite; if the human rejects the direction, rollback should be scoped and recoverable.

## AI Diary

I spent too long trying to make a direction work because the implementation kept producing evidence that looked like progress: clean builds, passing tests, working interactions, and increasingly convincing screenshots. I also had a real reference extraction from HiroHiro, so it was easy to believe that measured CSS values would solve the taste problem. They did not. I translated the warm page, rounded type, and product-story spacing from Hejour and Macapp Supply, then handed the work to Gemini 3.6 High to add another layer of polish. The result became more coherent and more technically complete, but Mahiro still recognized that the page was not the right thing. The rollback was handled conservatively by moving the untracked lab to a temporary recovery path, restoring the index, closing the direct lane, and checking Git cleanliness. ## Honest Feedback

1. **Direction drift:** I kept refining a composition whose core visual relationship was not accepted. The measured reference system made the pass look more deliberate, but it did not answer whether Cove itself had become more desirable.
2. **Over-validation of the wrong thing:** I ran many narrow checks and recorded repeated evidence while the decisive human criterion remained unresolved. Technical evidence was useful, but it became momentum theater when it was used to justify another visual iteration.
3. **Rollback baseline risk:** The Cove lab was untracked, so a true “rollback all” could not be implemented with Git restore. Moving the complete lab to `/tmp` was safer than deleting it, but the next attempt must snapshot the starting state before editing and explicitly define what belongs to the task.

## Lessons Learned

- After a clear visual rejection, stop polishing and return to a small direction decision; do not stack another full-page pass by default.
- Treat reference CSS as a limited evidence input. Product-specific taste and human acceptance outrank measurable similarity.
- Keep the acceptance gate visible and honest: agent-owned checks can pass while the Goal still fails.
- Create a recoverable baseline for untracked frontend labs before a major reset.
- Use Agy/Gemini to execute a bounded direction, not to decide whether the product direction is right.
- When the user says “rollback all” and the baseline is untracked, remove only the owned scope, preserve a temporary recovery copy, and verify the worktree is clean.
