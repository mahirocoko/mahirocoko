## Key Decisions

1. **Edge-connected is the safe default** for fur/fine edges and subjects with pink/magenta details near a magenta key. `spill` can clean dark-preview fringe, but it can also destroy real detail.
2. **Do not choose by dark preview alone.** Light, dark, checker, and source-detail preservation all matter.
3. **Master sprite first.** Animation generation compounds drift; approve one clean source frame before generating multi-frame motion.
4. **Center drift is not enough.** A frame can keep center near target while alpha bounds width/x drift causes a visible pop.
5. **Visual honesty beats green scripts.** Mahiro caught frame-06 jitter and forced the workflow to learn an actual QA blind spot.

## Honest Feedback

Three friction points stand out. First, I initially overtrusted dark-background inspection. Dark previews are useful for fringe, but they are only one lens; for this asset they biased me toward spill cleanup and away from preserving pink detail. Second, the early reports overstated certainty. I described winners before enough visual comparison across light/dark/checker and adjacent-frame zooms. That is exactly the kind of “pipeline says OK” behavior Mahiro dislikes, and this session corrected it. Third, the tooling was missing a subtle-loop concept. `qa-sprite-sheet.py` could gate sheet size, center, edge contact, residue, and slivers, but it did not understand that identical center plus wider silhouette can still jitter. The fix is now in the skill, but the lesson is broader: QA metrics must model what the eye notices in the target runtime, not just convenient numeric proxies.

## Lessons Learned

- Chroma-key imagegen output is usually an imperfect matte, not a true flat key, even when prompted strongly.
- `edge-connected` should be the default dicut mode for fur/fine edges and pink/magenta details near magenta.
- `spill` is a fallback, not a winner by default; it must clearly preserve real detail.
- Master-first reduces animation drift and makes later decisions less noisy.
- Bounds/silhouette stability is a required QA dimension for idle/subtle loops.
- Adjacent-frame zooms and preview GIFs should be first-class review artifacts, not ad-hoc debugging outputs.
- Promotion scripts need safe naming; generic `manifest.json`/`frames/*` promotion is risky in a shared `public/assets` folder.
