## Lessons Learned

- Approval should attach to specific artifact paths, not just “the latest candidate.”
- Named promotion is part of production hygiene for sprite assets.
- `production-draft` is a useful honest status for generated assets that are runtime-worthy but not hand-authored final art.
- Releasing the reusable workflow right after the task prevents the next session from re-learning the same dicut/motion problems.
- Project commits after asset work should include both final runtime artifacts and the local retrospective/learning notes that explain provenance.
