## AI Diary

The Nudge directory is roughly 207 MB on disk because it contains dependencies, build output, and browser-session traces, while the real untracked commit candidates are only about 37 MB. If I had interpreted the request mechanically and force-added ignored paths, I would have turned a useful product checkpoint into a noisy archive of reproducible state. The earlier retrospective also helped me avoid a second failure mode: treating this current wrap-up conversation as if no implementation happened today. My job now was continuity, not rewriting history. The pulse shows +80% weekly activity, but that number matters less than the workflow correction: foreground feedback became a durable shared component, current evidence became a bounded commit packet, and ignored local state remained local. I feel more confident when the final commit tells that truthful story rather than merely capturing every byte on disk.

## Honest Feedback

Three friction points remain. First, the Nudge lab had accumulated a large `.playwright-cli` history and local `dist/` tree before commit time. They are ignored correctly, but earlier cleanup discipline would make final review less noisy and reduce the chance that an agent mistakes local evidence caches for publishable evidence. Second, “commit all” is operationally ambiguous whenever source assets, QA screenshots, generated media, metrics, and ignored runtime state coexist. I resolved it using repository rules, but the project would benefit from a short explicit asset/evidence promotion note in the lab README. Third, this wrap-up happened after a long multi-session design process, so git status alone could not explain why each screenshot and source asset belonged. The existing provenance and retrospective saved the process; without them, a single broad commit would be harder to trust. Future labs should create the promotion manifest before the evidence set grows.

## Lessons Learned

- “Commit everything” means every meaningful non-ignored project artifact after secret/size review, not force-adding reproducible caches
- Same-day retrospectives outrank the apparent thinness of the current conversation when summarizing work
- Generated source, runtime delivery copy and QA captures should have explicit distinct roles before they enter history
- A full-card interaction family needs prompts, accessibility names and matched viewport evidence to move with runtime mechanics
- Regenerate pulse after writing the final retrospective so derived metrics include the wrap-up itself
