## Architecture Decisions

- Tilt Field เป็น **shared product contract** ไม่ใช่แค่หน้าที่สวยที่สุด
- Card preview ต้องเป็น compact truthful reduction ของ detail runtime เดียวกัน
- แต่ละ collection ใช้ dark ambient/generated-print grammar ร่วมกัน แต่ต้องมี interaction job ของตัวเอง
- Header background เป็น full viewport; content alignment อยู่ใน `.masthead__inner`
- Pointer motion เป็น progressive enhancement; touch/keyboard/reduced motion ต้องยังอ่านและใช้งานได้
- Prompt/spec ต้องอธิบาย runtime จริง ห้ามค้างอยู่กับ implementation รุ่นเก่า
- Motion เป็น anatomy evidence ไม่ใช่สิทธิ์คัดลอก brand, asset, pricing หรือ proprietary prompt

## AI Diary

I initially underestimated how far “technically complete” was from “visibly convincing.” The early Nudge work had routes, filters, prompt copy, reduced motion, and tests, yet the screen still read as a familiar dark card grid. My first instinct was to defend the originality boundary by differentiating too early. That protected against copying, but it also prevented me from learning the reference’s strongest compositional decisions. The turning point was looking at Motion and Helix as a sequence of product jobs rather than a style source: the media proves the idea first, controls stay attached to the proof, captions sit outside the media, and implementation depth follows only after curiosity is earned.

The second important correction came after Mahiro approved the improvement but asked to use Tilt Field as the main axis. I had to stop treating each collection as an isolated visual experiment. A shared component became the honest answer because it made the homepage preview and detail page literally the same runtime family. That refactor also exposed quality problems I might otherwise have missed: Travel Scrub’s intrinsic image width, Type Signal’s broken word wrapping, prompts describing obsolete markers, duplicate accessible link names, and the masthead background ending at the content rail. I felt the session became stronger when I treated those findings as product correctness rather than polish. The +60% weekly local session trend is encouraging, but the more meaningful momentum is that Mahiro’s direct visual feedback now becomes a reusable contract instead of another one-off patch.

## What Went Well

- Live reference study changed composition, not just colors
- Mahiro’s approval was translated into a reusable component/contract

## Honest Feedback

Three friction points mattered. First, the work took too many iterations because I allowed an intermediate architecture where Tilt Field was special-cased inside the detail page while cards still used a separate preview system. That was expedient but contradicted the product direction; the shared stage should have appeared immediately after Tilt Field became the accepted axis. Second, I generated and later deleted several rounds of screenshots. The evidence was useful, but capture naming and promotion should have been stricter so old states never sat beside current states long enough to confuse review. Third, I let copy lag behind runtime. The UI had already changed from lines and circular markers to six generated prints, but the copied AI prompt still described the old mechanism. That is not a cosmetic defect: users would build the wrong thing. Future work should update content contracts in the same patch as runtime ownership, and accessibility names should be checked whenever a whole card becomes one link.

## Lessons Learned

- “ใกล้ reference” ต้องวัดที่ anatomy, pacing, proof order และ control locality ไม่ใช่ palette
- เมื่อหนึ่ง section ได้รับการยอมรับเป็นแกนหลัก ให้ยกระดับเป็น shared contract ทันที
- Card preview ที่ดีควรเป็น runtime จริงใน compact mode ไม่ใช่ภาพประกอบอีกระบบ
- Generated assets จะดูเป็น product family เมื่อแต่ละ interaction จัดวาง archive เดียวกันด้วย grammar ร่วม ไม่ใช่ใช้ภาพเดียวซ้ำ
- Wide-screen header ต้องแยก full-bleed shell ออกจาก constrained inner rail
- Prompt text, notes, accessibility tree และ screenshots เป็นส่วนหนึ่งของ runtime truth
- Script pass ไม่พอ: actual-pixel QA พบปัญหา intrinsic sizing, clipping และ word wrapping ที่ tests ไม่เห็น
