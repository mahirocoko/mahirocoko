## AI Diary

The important correction in this session was resisting the temptation to turn design judgment into code. The first instinct after seeing the motionsites corpus was to add more extraction behavior, but the user correctly challenged that direction. The better pattern is thinner and more durable: scripts scaffold repeatable structure, while Markdown doctrine teaches the agent how to reason. Motionsites prompts are valuable because they are unusually explicit about fonts, media, timing, sections, and implementation details, but they are also full of exactly the aesthetic leakage `uncodixify` exists to catch. Treating them as anatomy rather than taste is the core move. The session ended with a cleaner skill ecosystem: `frontend-design` frames the brief, `uncodixify` filters the easy AI moves, `asset-designer` plans deliverable assets, and `web-asset-prompts` writes individual asset prompts.

## Honest Feedback

The main risk is that `brief` still contains a static scaffold in code. That is acceptable because it is deterministic and validated, but it should not grow into classification or extraction logic. Future improvements should favor `resources/brief-workflow.md` examples and checklist refinements over TypeScript heuristics. Another risk is bundling several cleanup concerns together: handoff archiving, `rive-agent` removal, frontend-design brief work, and adjacent skill boundary edits are coherent as a session cleanup, but they should be reviewed carefully before commit to decide whether one broad commit or smaller commits better preserves history.

## Lessons Learned

- Design-reference work should keep scripts as scaffolds and leave taste/judgment in docs.
- Scraped prompt corpora can teach prompt anatomy without becoming prompt canon.
- Motionsites-style specificity is useful for section, media, motion, and implementation contracts, but its liquid-glass/pill/cinematic patterns need `uncodixify` filtering.
- `asset-designer` and `web-asset-prompts` are separate phases: asset plan versus per-asset generation prompt.
- Validation for design skills should assert command structure and safety markers, not subjective design intelligence.
