## AI Diary
I felt the familiar tension between speed and correctness in this session. The user’s request was casual and practical — “scrape prompts and non-premium backgrounds” — but scraping is exactly the kind of work where a casual implementation can accidentally become brittle or ethically wrong. I had to slow myself down enough to ask for the missing URL, then treat site inspection and premium boundaries as first-class requirements instead of afterthoughts. The most useful moment was when verification contradicted my assumptions: first `networkidle` was too strict for the site, then not every background card had the image structure I expected, then clipboard behavior exposed a subtle race where copied content could remain stale. Each failure forced the script toward more real-world resilience. I also noticed that delegation helped gather site structure and repo conventions, but I still needed hands-on verification to catch browser-specific behavior. With a +62.5% weekly session change and a 6-day streak in the local pulse, the momentum is real, but this session reminded me not to let momentum turn into overconfidence. The final premium-content answer also mattered: technical capability is not permission. The script should embody that line, not merely mention it in docs.

## Honest Feedback
Three friction points stood out. First, the initial implementation trusted visible selector heuristics too much before a live dry-run proved the site’s loading behavior and card structure were more irregular than expected. I fixed it, but the better habit is to run the smallest browser verification as soon as the first selector-dependent version exists. Second, clipboard automation is deceptively stateful. Clearing or reading too quickly created misleading results, and the robust answer was not a clever one-off but a simple polling loop that waits for a changed value. Third, the first background extraction accepted copied prompt text as a failed media URL, which was safe but noisy; extracting embedded direct media URLs from copied text made the output more useful while keeping the public-media guard intact. The session ended in a solid place, but the scraper still depends on the site’s UI labels and DOM classes, so future maintenance should expect selector drift rather than treating this as permanently stable.

## Lessons Learned
- For public scrapers, “uncertain = skip” is the safest default, especially around premium markers and paywalls.
- Browser-driven copy buttons need clipboard polling or another deterministic wait; a fixed 100ms delay is too optimistic.
- `networkidle` can be the wrong readiness signal for media-heavy pages; visible target selectors are usually more reliable.
- A manifest is not just an output artifact — it is the audit trail proving what was copied, downloaded, skipped, and why.
- Follow-up asset types like thumbnails should reuse the same conservative media URL validation instead of adding a parallel trust path.
