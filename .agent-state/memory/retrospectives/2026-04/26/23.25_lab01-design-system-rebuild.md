## AI Diary
Today felt like a classic “ship, inspect, then unlearn” session. I started with confidence because the first pass matched the textual prompt, but as soon as the visual references (`1.png`, `2.png`, `3.png`) were treated as hard constraints instead of soft inspiration, I realized I had leaned too much on structural correctness and not enough on composition fidelity. The turning point was when the user called out that cloning wasn’t acceptable and that some sections still looked off. That was fair feedback, and it forced me to re-anchor on intent rather than convenience. I also noticed momentum from recent sessions: being on day 4 of a streak with a +120.0% weekly session change made it easier to stay persistent through many small iterations instead of stopping at “good enough.” I’m glad I kept verifying with screenshots and layout snapshots at each turn; otherwise subtle regressions would have slipped through. The biggest internal lesson is that design tasks need a stricter visual-delta loop than code tasks. Passing diagnostics is necessary, but never sufficient, for visual quality. I ended the session with a stronger alternate composition and cleaner asset discipline.

## Honest Feedback
I hit three friction points that slowed quality. First, I initially produced a clone frame when the user asked for another frame; technically fast, but it violated the spirit of the request. I corrected it, but I should have defaulted to variation-first. Second, I introduced a path/render mismatch during canonical asset swapping: the files existed, yet the layout looked blank because fill mode and slot ratio interactions were not evaluated immediately. I fixed this with targeted screenshot checks and `fit` mode updates, but that detour was avoidable with earlier ratio-aware mapping. Third, my early lower-page polish was still too compressed compared with `3.png`; Oracle soft-fail feedback confirmed what the user felt. The process worked, but I needed one extra review cycle to get the density, spacing, and visual weight right. Overall, I did recover well through verification loops, but I can reduce churn by enforcing stricter anti-clone and ratio-fit checks before presenting “done.”

## Lessons Learned
- In design generation tasks, “no layout problems” is only a floor; visual similarity to reference composition is the real acceptance gate.
- When assets are canonicalized, verify both path resolution and fill mode against slot ratio immediately.
- “Create another frame” should default to deliberate compositional divergence, not duplication.

## Next Steps
- Add a preflight checklist for design tasks: reference-delta targets, anti-clone requirement, and ratio-to-fill-mode mapping.
- Keep a reusable section-zoom verification routine (products/testimonial/journal/CTA/footer) for rapid mismatch detection.
- If asked next, produce 1–2 additional alternate compositions with explicit layout strategy labels (editorial split, modular grid, narrative band).
