# Superpowers is best read as a workflow system, not just a plugin

When learning repositories like `obra/superpowers`, treat the skill graph and workflow contracts as the primary product. The important logic is not only in runtime code or plugin entrypoints, but in how `skills/*` orchestrate behavior across brainstorming, planning, execution, review, verification, and branch completion.

For durable understanding, pair a deep repository study with two outputs: detailed reference notes and one compressed primer for fast re-entry. If a subagent fails during exploration, recover surgically by filling the missing artifact rather than repeating the whole learn pass.
