# Cove One failed direction and rollback

The 2026-07-26 Cove One Gate 2 rebuild passed technical checks and used real HiroHiro source/computed-style captures plus an Agy/Gemini 3.6 High implementation lane, but Mahiro rejected the visual result. The attempt was rolled back completely from the untracked lab scope and the Goal was left blocked rather than accepted.

Durable process rules:

- Measured reference CSS does not validate product taste. After a clear visual rejection, stop full-page polishing and ask for a small, explicit direction decision.
- Browser/build/test evidence proves implementation health only; it cannot satisfy a human visual gate.
- Agy/Gemini can implement or critique a bounded direction, but cannot decide product acceptance.
- For untracked frontend labs, snapshot the baseline before major changes. On rollback, move the exact owned scope to a recoverable temporary path, restore any shared index files, close direct lanes, and verify `git status` is clean.
- Do not revive this Cove pass implicitly. A future attempt needs a fresh direction packet and new Goal.
