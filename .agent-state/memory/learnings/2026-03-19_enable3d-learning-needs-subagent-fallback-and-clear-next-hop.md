# Enable3d learning needs subagent fallback and a clear next hop

This session exposed three connected patterns.

## Pattern 1 - Learn flows need graceful fallback

When a repo-learning workflow is written as if parallel subagents always exist, the experience becomes brittle in environments where those agents are disabled. The work can still succeed, but only if there is a deliberate fallback sequence. The stable manual sequence from this session was: inspect package map, read entrypoints, identify core abstractions, confirm usage in examples, and verify expectations in tests. **Confidence: high.**

## Pattern 2 - Research becomes durable when distilled immediately

The `enable3d` pass became valuable because it did not stop at code reading. The source was cloned into `.agent-state/learn`, then translated into three durable docs and finally summarized in Thai. That created three levels of utility: future machine reference, future human reference, and immediate comprehension. This matches the broader repository pattern that discovery work should move quickly from raw input to retained knowledge. **Confidence: high.**

## Pattern 3 - The best post-learn move is often a sandbox, not a full integration

After understanding `enable3d`, the most natural next action was not to force the actual package into the current repo. The better move was to create a small standalone website that borrows the architecture's feel: scene lifecycle, motion, overlay UI, and playful 3D energy. That keeps the learning alive while controlling complexity. **Confidence: medium-high.**

## Connection to prior memory

This reinforces earlier local lessons that behavior lock matters as much as content quality and that discovery work should end in reusable synthesis. It also echoes the recent trace lesson that disabled agent profiles should not collapse the whole workflow.

## Practical rule

For future `/learn` sessions: if subagents are unavailable, fall back immediately instead of fighting the intended path. Preserve the result as a local learn set, then convert the learning into the smallest meaningful artifact that exercises the new understanding.
