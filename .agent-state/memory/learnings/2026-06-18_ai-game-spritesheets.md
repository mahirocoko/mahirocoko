# ai-game-spritesheets learning note

Learned via `/learn --deep https://github.com/chongdashu/ai-game-spritesheets`.

Key takeaways for future sprite work:
- Treat sprite generation as a staged asset pipeline, not a single combined-sheet prompt.
- Keep durable references/guides: anchors, grids, contact sheets, previews, and runtime strips.
- Normalize after generation: alpha bounds, consistent frame size, foot baseline, stable scale, and contact-sheet/GIF QA.
- Markdown prompt templates can be a practical public API for asset workflows when no executable code exists.
