# สอน AI ให้จำเก่ง ไม่ต้องเริ่มใหม่ทุกแชต

## ใจความจากคลิป

ความทรงจำของ agent ไม่ใช่แค่ข้อความที่คล้ายกับคำถาม ผู้พูดเสนอให้จัดความรู้เป็นไฟล์ที่มีโครงสร้างและลิงก์ แล้วใช้ reasoning เลือกอ่านส่วนที่เกี่ยวข้อง แทนการพึ่ง vector similarity อย่างเดียว

## ช่วงสำคัญ

- **00:00–01:20** ปัญหาเมื่อเริ่ม session ใหม่: agent ลืมคำสั่ง วิธีรันโปรเจกต์ และสิ่งที่ตกลงไว้ จึงต้องอธิบายซ้ำ
- **01:21–03:15** ผู้พูดแย้งว่าความคล้ายทาง embedding ไม่เท่ากับการ recall เรื่องที่ถูกต้อง และยก PageIndex กับผลบน FinanceBench เป็นตัวอย่างของ reasoning retrieval
- **03:15–03:57** แบ่งงานเป็น indexing และ retrieval: index มีลำดับชั้นกับ summary ของแต่ละ node ส่วน retrieval ไล่ตาม node เพื่อหาเนื้อหาที่ตอบคำถามได้
- **03:57–05:36** ประยุกต์แนวคิดกับ filesystem: โฟลเดอร์และไฟล์เป็น tree ส่วนลิงก์ข้ามไฟล์ช่วยเชื่อมเป็น graph โหลดแผนที่ความรู้ให้ agent วางแผนก่อนอ่าน ถ้าแผนที่ใหญ่ก็จำกัด depth
- **05:36–06:34** ใช้เครื่องมืออ่านและค้นไฟล์ที่ agent มีอยู่แล้วเพื่อดึงความทรงจำกลับมา โดยไม่ต้องเพิ่ม vector database
- **06:34–08:23** การเขียน memory ต้องมีรูปแบบเชื่อมโยง และต้องจัดการ concurrent writes เมื่อมีหลาย session รวมถึง reindex หรือ consolidation เพื่อลดข้อมูลซ้ำและดูแลความทรงจำที่ไม่ใช้
- **08:23–จบ** แนะนำ agentmem ของผู้พูดสำหรับ memory layer ที่ใช้กับหลาย harness ได้

## สิ่งที่น่าเอามาใช้

เริ่มจากแผนที่ความรู้ที่สั้นและอ่านรู้เรื่อง แล้วค่อยเปิดไฟล์รายละเอียดตามคำถาม แต่ละ memory ควรระบุว่าพูดถึงอะไร มีที่มาเมื่อไร และเกี่ยวข้องกับไฟล์ไหนบ้าง

สำหรับหลาย session ปัญหาไม่ได้จบที่ค้นเจอ ต้องป้องกันการเขียนทับและแยกข้อมูลปัจจุบันออกจากข้อมูลเก่าด้วย การรวม memory ซ้ำไม่ควรทำให้ที่มาหรือเหตุผลของข้อสรุปหายไป

## เทียบกับ workflow ของ Mahiro

โครงสร้างที่ใช้อยู่มีแนวคิดใกล้กันแล้ว: memory blocks เป็นข้อมูลหลักและทางเข้าหัวข้อ, project router ชี้ไปไฟล์เฉพาะเรื่อง, ลิงก์เชื่อมรายละเอียด และ Git เก็บประวัติการเปลี่ยนแปลง ส่วนนี้เป็นข้อสังเกตของ Main ไม่ใช่คำกล่าวจากคลิป และไม่ได้พิสูจน์ว่าระบบปัจจุบันมีประสิทธิภาพเท่ากับ PageIndex หรือ agentmem

ถ้าจะประเมินเพิ่ม ควรทดสอบคำถามจากงานจริงว่าหา memory ที่ถูกต้องได้ไหม ใช้กี่ไฟล์และกี่ token รวมถึงแยกข้อมูลปัจจุบันกับอดีตได้หรือไม่ ก่อนเปลี่ยนระบบหรือเพิ่มเครื่องมือ

## ขอบเขตหลักฐาน

- บันทึกนี้อ่านจาก captions ภาษาไทยของ YouTube ไม่ใช่การตรวจภาพและเสียงครบทั้งคลิป captions มีคำทับศัพท์ผิด จึงปรับเฉพาะคำในสรุปให้อ่านรู้เรื่องและเก็บ SRT ต้นฉบับแยกไว้
- Gemini ปฏิเสธหรือดึง transcript ไม่ได้ คำตอบอีกตัวเลือกพูดถึง Custom Instructions และ Projects แต่ไม่ตรงกับ captions จึงไม่นำมาใช้เป็นเนื้อหาสรุป
- ตัวเลข FinanceBench ประมาณ 98.7% เทียบกับช่วง 50–80% และคำว่า state of the art เป็น claims ของผู้พูด ยังไม่ได้ตรวจ paper, benchmark setup หรือ baseline อย่างอิสระ
- ผล QA บนเอกสารการเงินไม่ใช่หลักฐานโดยตรงว่า agent memory ทุกงานจะดีขึ้น และคลิปนี้ไม่พิสูจน์ว่า vector retrieval ใช้ไม่ได้กับทุกกรณี
- ยังไม่ได้ดาวน์โหลด ติดตั้ง หรือทดสอบ agentmem
