# Reference fidelity needs role-complete replacement and typed browser control

**Date:** 2026-07-19  
**Tags:** frontend-reference, fidelity, imagegen, HiroHiro, browser-control, MCP, accessibility, QA

## Durable lesson

When Mahiro asks for a high-fidelity learning reconstruction, IP/source caution must not silently remove important visual roles. Map the complete visible page anatomy and interaction system first, then preserve each role through one of four explicit decisions:

- **Keep:** layout job, material relationship, timing, or interaction pattern
- **Adapt:** product identity, wording, geometry, and implementation
- **Generate:** original logo/media/portrait/proof assets for roles that would otherwise be missing
- **Reject:** copied pixels, identities, unverifiable customer claims, executables, or source-specific product behavior

High fidelity requires more than section order. Verify:

1. button dimensions/material/hover/focus
2. timed states and transition ownership
3. autoplay pause/control and reduced-motion parity
4. truthful static and interactive affordances
5. complete mobile and footer anatomy
6. named screenshot postconditions

Use HiroHiro for live-reference evidence: controlled-tab inspection, computed CSS, section captures, timed states, and trusted clicks with checked postconditions. Use one serial Playwright lane as a complement for viewport, reduced-motion, network, console, and deterministic geometry evidence.

## HiroHiro product direction

Do not rewrite HiroHiro around MCP. Preserve the extension and local bridge as the core protocol, then add adapters:

- existing CLI for scripts and debugging
- thin stdio MCP adapter for typed agent tools
- workflow skill for sequencing, safety, and evidence quality

MCP should expose read-only tools first and capability-gate trusted interaction. It should preserve tab ownership, command IDs, locks, token/localhost boundaries, circuit breaking, and explicit control release. Avoid arbitrary eval as a default tool.

## Trigger

Apply this lesson whenever a task says “make it like this,” asks for the same button/animation feel, supplies a live reference, permits generated replacements, or repeatedly uses HiroHiro's CLI through shell JSON.
