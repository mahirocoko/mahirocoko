# AI Reliability Guardrails

This folder now separates the material into two focused documents:

- [`global-claude-guardrails.md`](./global-claude-guardrails.md) — a reusable block for `CLAUDE.md` or similar assistant instruction files
- [`agents-md-writing-guide.md`](./agents-md-writing-guide.md) — a reusable guide for writing effective `AGENTS.md` files
- [`shareable-post.md`](./shareable-post.md) — a polished public-facing post version in Thai

The core idea remains the same:

> Do not present unverified inference as fact.

Use the global file when you want implementation-ready instructions.

Use the shareable post when you want a cleaner explanation for other people.
