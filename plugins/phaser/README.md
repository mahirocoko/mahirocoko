# Phaser Codex Plugin

This plugin packages the Phaser skill set from `phaserjs/phaser`.

Source:

- Imported commit: `8dc8b145d8e8a7bc05e748c8ee223333f4d46320`
- Import date: 2026-04-26

The plugin exposes the imported skill directories through `.codex-plugin/plugin.json` with `skills` set to `./skills/`.
