# Whisperfield image-generation prompts

These prompts are production web-asset contracts. Generate each family independently; do not generate a whole webpage and crop it apart.

## 1. Mark candidate sheet

**Asset mode:** transparent-cutout source / logo-reference sheet  
**Ratio:** 1:1  
**Output:** PNG source sheet  
**Delivery intent:** source for one final SVG redraw

```text
Create a clean 2×2 candidate sheet of four distinct original geometric symbol marks for a fictional quiet voice-workflow product named Whisperfield. Marks only—no wordmark, letters, text, microphone icons, soundwave clichés, speech bubbles, Apple shapes, VoiceOS shapes, or existing app-logo geometry. Each mark should express a thought moving through a calm field: compact, bold, legible at 16px, one-color black with one restrained coral accent, flat vector-like edges, centered in its own evenly spaced cell on a plain warm-white background. No gradients, shadows, mockups, labels, watermark, frame, or clipped edges. Keep generous padding and clean separation between cells.
```

## 2. Hero corner cloud source

**Asset mode:** chroma-key cutout source  
**Ratio:** 1:1 2×2 sheet  
**Output:** PNG source sheet on `#00ff00`  
**Delivery intent:** production after dicut

```text
Create a 2×2 source sheet containing four separate airy cloud banks for website corner compositing: top-left wisps, top-right wisps, bottom-left fuller cloud, bottom-right fuller cloud. Perfectly flat solid #00ff00 chroma-key background, exactly one uniform key color with no wall, floor, gradient, texture, reflections, or green spill. Soft photoreal cloud volume with pale ivory, cool lavender, and the faintest coral dawn rim; calm premium atmospheric photography, not fantasy illustration. Every cloud is fully visible with generous padding and separated from neighboring cells. No text, logo, watermark, border, cast shadow, sun, landscape, or clipped edge. Do not use #00ff00 in the clouds. The extracted transparent assets must remain readable over white.
```

## 6. Fictional customer avatar sheet

**Delivery intent:** production after crop

