Whisperfield Preview Pack
=========================

Whisperfield is a fictional voice-workflow frontend study. This archive contains
only original generated visual assets and a copy of this note. It is not a Mac
application, installer, account, or working voice product.

Included visual roles:
- Whisperfield symbol mark
- product-stage daylight sky
- privacy-stage night sky
- closing sunrise sky
- four transparent hero cloud corners
- six fictional field-note avatars

assets/imagegen/provenance.md
