## 2. Shared Visual DNA Across Both Artifacts

Both compositions are unified by a cohesive, high-restraint visual system tailored for modern macOS power users and creative technologists:

1. **Stark Optical Canvas & Extreme Restraint**:
   - Website canvas relies on pure, stark off-white (`#FBFBFD`) with macro whitespace and zero ornamental background noise, mesh gradients, or blur clutter.
   - App workbench is anchored in deep obsidian and ebonite glass (`#16161A` / `#111114`) with dark-mode ambient self-luminance and authentic 1px inner hairline perimeter strokes (`rgba(255, 255, 255, 0.12)`).

2. **The Signature Visual Element: The Optic Blade**:
   - The central functional and visual anchor in both compositions is the **Optic Blade**: a razor-sharp 1px hairline divider with an integrated 28px circular crosshair loupe reticle.
   - It performs the visual split between uncalibrated raw source inputs and verified, calibrated derivative states, accompanied by technical telemetry capsules (`P3 ➔ sRGB`, byte reductions, and stripped tag counts).

3. **Strict Typographic Character**:
   - Refined geometric neo-grotesque sans-serif typography restricted strictly to **400 Regular** and **500 Medium** weights (eliminating visual heaviness and avoiding proprietary font claims).
   - Paired with strict monospaced tabular figures with slashed zeros for all dimensional telemetry, byte metrics, and metadata readouts.

4. **Authentic Material & Color System**:
   - Minimalist neutral palette: Off-White (`#FBFBFD`), Obsidian Black (`#0A0A0C`), Studio Grey (`#86868B`), and Hairline Grey (`#E5E5EA`).
   - High-precision functional accents: Optic Cyan (`#0066CC` / `#2997FF`), Warning Amber (`#FF9500` / `#FF9F0A` for detected privacy tags), and Calibrated Emerald (`#34C759` / `#30D158` for clean verification).

5. **Absolute Elimination of Generic Tropes**:
   - Explicitly forbids Apple logo glyphs, SF Symbols, SF Pro claims, physical laptop mockups (MacBook frames/hands), generic SaaS purple-pink mesh gradients, card-grid anatomy, and cartoon illustrations.

## 3. Rigorous Application of Product Truths

In accordance with product-truth directives, both prompt specifications adhere strictly to the following boundaries:

1. **Local Single-Asset Scope**:
   - Staging is strictly limited to a single image or PDF preflight. Multi-file batch queues, cloud links, and gallery lists are excluded.
2. **Explicit Inspectable Facts Only**:
   - UI readouts display only verifiable metadata facts: pixel dimensions (`2880 × 1800 px`), byte weight (`8.4 MB`), exact color profile (`Display P3`), and detected tag categories (`GPS Geotag`, `Device Model`, `Creation Timestamp`).
3. **Explicit User-Selected Derivative Steps**:
   - Transformations (gamut conversion, metadata stripping, lossless squash) are presented as deliberate, user-selected checklist actions.
   - Both interfaces prominently confirm that the **original source file remains untouched on disk**, producing an isolated derivative for drag-and-drop sharing.
4. **No Impossible Claims**:
   - Completely removes claims of universal PII detection, complete safety, universal format support, or ironclad guarantees. Replaced with objective technical statements ("14 Metadata Tags Detected", "Gamut Converted to sRGB IEC61966-2.1").
5. **Provisional Working Name**:
   - "Vessel" is designated as a provisional working title with pre-release markers (`v0.1-alpha`, `LOCAL SINGLE-ASSET PREFLIGHT`).
