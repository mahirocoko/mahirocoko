## Shared visual constraints

- Contemporary editorial still life / landscape, analogue grain, controlled late-afternoon side light, restrained teal/cobalt/amber/stone palette.
- No logos, text, labels, watermarks, recognizable brands, famous locations, celebrities, or copied editorial/film stills.
- Each image must be independently composed as a portrait print with subject-safe crop room, not a crop from a full-page mockup or contact sheet.
- Use six distinct source files. Preserve the source output separately from runtime promotion.

## Runtime contract

- Promote accepted output to `public/assets/gallery/` as PNG initially; keep the generated source path/provenance in this manifest.
- CSS card containers use `object-fit: cover`, 4:5 portrait ratio, and rounded corners. Source needs at least 8% visual breathing room around the focal subject.
- QA on Nudge dark canvas, the light print frame, and at 390px card crop.
