# Wavebreak Defense

A small 2D tower defense prototype built with Phaser, TypeScript, and Vite.

## Play Loop

- Build towers on marked grove circles during planning.
- Start the next wave when ready.
- Enemies follow the forest lane toward the crystal.
- Defeating enemies grants gold; clearing a wave grants a bonus.
- Clear all five waves before lives reach zero.

## Art Direction

The concept image in `public/assets/wavebreak-concept.png` was generated with the built-in image generation workflow and used as the visual direction for the forest path, copper towers, teal crystal magic, and coral enemy accents.
