# Full Page Design Handoff

Use `demo01.png` as the primary visual reference.

## Core Intent

Design and implement a complete premium editorial wellness landing page in plain HTML and CSS.

The result should feel like:

- luxury editorial wellness
- clean clinical meets botanical luxury
- calm, premium, airy, trustworthy, and precise

This is not a generic SaaS landing page, not a dashboard, and not a heavy e-commerce storefront.

## Output Rules

- Return one complete HTML document only
- Include embedded CSS inside a `<style>` tag
- No markdown fences
- No explanations
- No fragments or component snippets
- No log viewer, admin UI, or unrelated interface
- Plain HTML and CSS only
- Make it responsive

## Visual System

### Palette

- background: warm cream, soft ivory, porcelain off-white
- text primary: deep olive-black
- text secondary: muted sage-gray
- accent: deep forest green
- border: very light warm gray
- surfaces: soft off-white and clean white cards

### Typography

- display: elegant high-contrast serif for large editorial headings
- ui/body: restrained sans-serif for nav, metadata, body copy, and stats
- strong contrast between serif display and quiet functional text
- large typography should feel airy and high-end, not aggressive

### Spacing and Surfaces

- very generous vertical rhythm
- spacious section padding
- narrow, disciplined content width where appropriate
- premium rounded cards with subtle shadows
- thin dividers and precise spacing
- minimal decorative noise

## Page Structure

Build the full page with these sections in order.

### 1. Top Navigation

Create a refined navigation bar.

- left: `Manifesto`, `Science`, `Journal`
- center: brand mark and `VITALIS`
- right: `Login` and a dark green rounded CTA such as `Get Started`

Style:

- thin divider below nav
- understated small text
- elegant spacing
- premium restraint

### 2. Hero

Create a centered hero section with:

- a small muted brand or trust row above the headline
- a very large serif multi-line headline
- concise supporting copy in muted gray-green
- one compact dark green CTA button

Match the screenshot mood closely:

- warm cream background
- wide breathing room
- strong centered composition

### 3. Hero Card Strip

Create a three-column card row directly below the hero.

Card 1:

- large food or lifestyle image
- tiny caption like `Daily calibration`

Card 2:

- clean white product or nutrition card
- title like `Macro-Bowl V2`
- one-line supporting description
- lower stat rows such as Protein, Fiber, Net Carbs

Card 3:

- portrait or botanical lifestyle image
- overlaid editorial statement

All cards should:

- share generous rounded corners
- have subtle shadows
- feel balanced and premium

### 4. Editorial Quote Section

Add a large centered serif quote section with major whitespace around it.

- oversized editorial quote
- minimal supporting elements
- quiet pacing

### 5. Core Bio-actives / Ingredient Gallery

Create a section inspired by the screenshot continuation.

- left-aligned section title: `Core Bio-actives`
- short supporting line like `Sourced from regenerative soil.`
- subtle arrow controls on the right if useful
- below that, create a refined ingredient grid or carousel-like layout

Use cards or blocks that suggest:

- leaf extract
- tonic vessel
- root or mineral source
- avocado or botanical nutrient imagery

### 6. Protocol / How It Works

Create a structured explanation section for the system.

Use 3 steps with quiet numeric markers:

- `01 Source`
- `02 Formulate`
- `03 Restore`

Each step should be short, precise, and credible.

### 7. Science Split Section

Create a split layout that balances luxury branding with scientific clarity.

- one side: large serif subheadline
- other side: concise explanatory text and short principle bullets

Possible thematic bullets:

- polyphenol diversity
- micronutrient density
- microbiome support
- metabolic steadiness

### 8. Featured Products

Add a premium product preview section.

- 2 or 3 product cards
- not loud e-commerce
- quiet labels, benefit lines, and subtle CTAs like `View protocol`

### 9. Testimonial / Trust Section

Add a refined trust section.

- one large testimonial or a few small quotes
- use serif quote styling and quiet attribution
- avoid noisy logo-wall marketing

### 10. Journal Preview

Add a journal or education section.

- 3 article cards
- typography-led layout
- editorial image crops and short excerpts

### 11. Final CTA Section

End with a calm but confident CTA block.

- serif heading such as `Begin the protocol`
- one short support line
- two restrained CTAs such as `Explore Menu` and `Read the Science`

### 12. Footer

Create a quiet footer.

- brand and short positioning line
- grouped links for Product, Science, Journal, Contact, Legal
- keep it elegant and uncluttered

## Motion Sensibility

Do not implement heavy motion systems, but keep the design motion-ready.

- soft fade and rise entry logic
- subtle hover behavior only
- no aggressive parallax
- no flashy interaction design

## Important Avoid List

Avoid all of the following:

- generic SaaS aesthetics
- dashboard styling
- loud gradients
- web3 or crypto feeling
- dense icon grids
- glassmorphism
- badge overload
- e-commerce clutter
- thick borders
- harsh black and white contrast

## Final Instruction

Recreate the composition and feeling of the screenshot as closely as practical while extending it into a coherent full landing page. Keep the result beautiful, restrained, high-end, and consistent from top to bottom.
