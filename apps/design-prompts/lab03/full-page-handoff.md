# Full Page Design Handoff

Use this file as a page-specific handoff layered on top of the existing `frontend-design compose` baseline.

Do not override the upstream output contract from the composed prompt stack. This file is only for page-specific structure, messaging, and visual direction.

Compact standalone brief (plain HTML + CSS, no compose stack): see `prompt.txt` in this folder.

The page should present an indie narrative game studio that feels:

- restrained but atmospheric
- playable before decorative
- craft-led but commercially clear
- specific, readable, and accessible

This is not a generic startup site, not a dashboard UI, not a pricing page, not a streamer overlay, and not a loud cyberpunk game teaser.

## Handoff Scope

- preserve the upstream output-format rules from the composed prompt stack
- use this handoff to define page structure, content priorities, visual tone, and constraints specific to the indie game-studio brief
- keep the result responsive, semantic, and polished
- apply restrained `uncodixify` judgment: remove fake-premium SaaS moves, decorative filler, glass panels, pill overload, generic metrics grids, uppercase label spam, and repeated corner-frame decoration

## Core Studio Framing

Create a landing page for a small studio making story-led games with strong environmental atmosphere.

Suggested studio name:

- `Hollow Signal Studio`

Suggested current title:

- `Northstar After Dark`

Studio positioning:

- narrative games about memory, weather, and places that feel lived in
- compact teams, deliberate production, playable prototypes, and accessible releases
- cinematic visuals used to support story and interaction rather than pure spectacle

## Visual System

### Palette

- background: near-black, charcoal, old ink, or dark umber
- text primary: warm off-white or low-glare bone
- text secondary: muted warm gray, ash, or weathered stone
- accent: restrained amber, oxidized brass, rust, or clay used sparingly
- surface: dark panels with subtle tonal changes, not glass shells
- border: thin low-contrast warm-gray dividers

### Typography

- use one readable sans-serif family for headings, navigation, body copy, buttons, and links
- use scale and spacing for hierarchy instead of decorative font pairing
- avoid uppercase label spam, tiny metadata layers, and section-number systems unless they solve a real navigation problem
- typography should feel like a serious studio site, not a startup template

### Spacing and Surfaces

- use image-led sections with clear reading paths
- preserve disciplined grid alignment and calm spacing
- use simple dividers and plain bordered media only where they clarify structure
- prefer normal rows, split panels, and concise lists over repeated generic cards
- keep corners restrained and shadows minimal

## Messaging Rules

The page must avoid empty game marketing hype.

Instead, use specific production-aware details such as:

- playable demo status
- platforms under consideration or confirmed
- localization plans
- accessibility passes
- festival or press preview framing
- shipped titles, prototypes, or team craft signals

Every credibility claim should feel grounded and inspectable.

Examples:

- a demo build shown at a small festival, not vague global domination
- two shipped narrative titles, not invented blockbuster credentials
- subtitles, remappable controls, and contrast checks, not hand-wavy “inclusive by design” copy

## Page Structure

Build the page with these sections in order.

### 1. Top Navigation

Create a restrained navigation bar.

- left: `Games`, `Approach`, `Updates`, `Press`
- center or left: studio mark and `Hollow Signal Studio`
- right: `Play the Demo` and `Press Kit`

Style:

- thin divider or quiet frame line
- dark editorial spacing
- understated typography
- no glassmorphism or floating nav shell

### 2. Cinematic Hero

Create a large image-led hero section.

Include:

- a concise context line such as `Independent narrative games · founded in 2019`
- a large headline such as `Small stories with the weight of weather`
- concise supporting copy focused on narrative craft, current title, and production clarity
- one primary CTA and one secondary CTA
- a dominant cinematic still or illustrated frame
- one or two production notes for demo build, platforms, festival preview, or accessibility pass

Hero mood:

- cinematic and quiet
- image-led, not widget-led
- strong negative space
- restrained technical metadata

### 3. Featured Games

Show two or three projects.

Suggested titles:

- `Northstar After Dark` — a quiet road mystery about a radio operator following storm signals across an empty coastal highway
- `Moth House` — a domestic ghost story built around room-scale puzzles and overheard conversations
- `Low Tide Almanac` — a short-form walking sim about archival field notes, migration, and shoreline memory

For each game include:

- title
- one-sentence premise
- status such as demo available, in production, or prototype archive
- platform or release note
- cinematic still or self-contained visual

Use editorial rows, split layouts, or image-led panels rather than a generic equal-card grid.

### 4. Studio Approach

Explain how the studio makes games.

Include content around:

- narrative systems tied to place and memory
- environmental storytelling before exposition
- prototype-led production
- accessibility and localization considered early
- small-team art direction and sound design

Design this section like a process note from a serious studio, not a capability grid from a SaaS page.

### 5. Proof Strip

Add a clean proof strip.

Use 3 or 4 concrete studio facts such as:

- `2 shipped narrative titles`
- `9 language subtitle plan`
- `1 playable demo in festival circulation`
- `remapping + subtitle + contrast checks in every milestone`

These should read as grounded credibility signals, not dashboard KPI cards.

### 6. Current Update / Press

Create an editorial update section.

Include:

- one current production update for `Northstar After Dark`
- one press excerpt, announcement, or festival note
- a link-style CTA for reading the full update or downloading the press kit

Keep this section concise. Avoid quote walls, testimonial spam, and logo walls.

### 7. Final CTA

End with a calm but clear CTA block.

- headline such as `Step into the next build when the lights go down`
- one short support line
- primary CTA: `Play the Demo`
- secondary CTA: `Download Press Kit`

### 8. Footer

Create a minimal footer.

- studio mark and short positioning line
- grouped links for Games, Studio, Updates, Press, Legal
- practical contact or press email
- restrained visual treatment

## Design Details

Add only careful high-value details:

- thin frame lines
- subtle image masks and cinematic crop ratios
- compact production notes
- plain dividers instead of section-number systems
- no repeated corner markers or decorative frame ornaments
- restrained hover cues and visible focus states

## Avoid List

Avoid all of the following:

- generic SaaS hero layouts
- pricing, integrations, dashboards, KPI cards, or logo walls
- fake premium copy
- loud neon cyberpunk styling
- streamer-overlay aesthetics
- heavy glassmorphism
- heavy gradients
- pill overload
- big icon grids
- repetitive equal-card sections that make the studio feel template-generated
- decorative corner frames repeated across every image
- footer links that all point to the same placeholder anchor
- vague hype such as “the future of gaming” or “world-changing experiences”

## Final Instruction

Create a coherent indie narrative game-studio landing page that feels dark, editorial, image-led, and production-aware. Make the studio desirable through atmosphere and craft, then trustworthy through concrete release details, accessibility posture, and concise updates. Keep the page restrained enough that the games remain the focus.

## Revamp Constraint

For the current lab03 implementation, prioritize a normal, readable studio site over a cinematic poster. Keep the same content arc, but reduce decoration: fewer metadata labels, two button styles only, simple bordered media, no corner-frame pseudo-elements, no heavy shadows, and no proof section that looks like dashboard KPIs.
