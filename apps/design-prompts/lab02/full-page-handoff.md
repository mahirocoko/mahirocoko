# Full Page Design Handoff

Use this file as a page-specific handoff layered on top of the existing `frontend-design compose` baseline.

Do not override the upstream output contract from the composed prompt stack. This file is only for page-specific structure, messaging, and visual direction.

Compact standalone brief (plain HTML + CSS, no compose stack): see `prompt.txt` in this folder.

The page should present an electric vehicle brand that feels:

- advanced but calm
- premium but responsible
- performance-led but sustainability-aware
- elegant, precise, and trustworthy

This is not a generic startup site, not a dashboard UI, not a loud concept-car microsite, and not a vague “green” marketing page.

## Handoff Scope

- preserve the upstream output-format rules from the composed prompt stack
- use this handoff to define page structure, content priorities, visual tone, and constraints specific to the eco-car brief
- keep the result responsive, semantic, and polished

## Core Product Framing

Create a brand for a premium electric crossover or sedan.

Suggested brand name:

- `AERION E1`

Brand positioning:

- aerodynamic electric mobility for modern cities and long-distance escapes
- premium comfort with measurable sustainability choices
- confidence through clean engineering, fast charging, and material transparency

## Visual System

### Palette

- background: soft mineral white, warm gray, or pale stone
- text primary: graphite or near-black charcoal
- text secondary: muted slate or sage-gray
- accent: restrained moss green, muted teal, or electric blue used sparingly
- surface: off-white, brushed gray, and smoked dark sections for contrast moments
- border: thin cool-gray or warm-gray dividers

### Typography

- display: refined modern serif or crisp premium display sans for hero moments
- ui/body: clean sans-serif for navigation, specs, supporting copy, and labels
- use strong hierarchy contrast between large hero typography and small technical metadata
- typography should feel premium automotive and editorial, not startup-generic

### Spacing and Surfaces

- use large image-led sections with generous breathing room
- preserve disciplined alignment and calm spacing
- use subtle shadows and premium corner radius
- prefer precise cards and structured sections over crowded marketing blocks
- add quiet grid logic or technical alignment lines when useful

## Messaging Rules

The page must avoid vague sustainability claims.

Instead, use specific and qualified proof such as:

- estimated battery range
- 10–80% fast-charge timing
- recycled aluminum or recycled textile percentages
- bio-based or responsibly sourced interior materials
- lower-emission production framing with careful wording

Every sustainability claim should be paired with a clear performance or craftsmanship benefit.

Examples:

- lighter recycled aluminum supports efficiency and range
- recycled cabin textiles still feel premium and durable
- fast charging supports real-life convenience, not abstract eco virtue

## Page Structure

Build the page with these sections in order.

### 1. Top Navigation

Create a refined navigation bar.

- left: `Vehicle`, `Sustainability`, `Technology`, `Journal`
- center: brand mark and `AERION E1`
- right: `Book a Drive` and `See Availability`

Style:

- thin divider or subtle transparent border
- premium, quiet spacing
- understated typography

### 2. Hero

Create a large image-led hero section.

Include:

- a small label such as `Electric grand touring, responsibly engineered`
- a large headline such as `Drive further with a lighter footprint`
- concise supporting copy focused on range, comfort, and credible sustainability
- one primary CTA and one secondary CTA
- a dominant premium vehicle image
- one or two small spec chips for range, charge time, or recycled content

Hero mood:

- editorial and premium
- calm confidence
- strong product photography
- restrained technical detail

### 3. Metrics / Proof Strip

Add a clean proof strip directly beneath the hero.

Use 3 or 4 measurable blocks such as:

- `610 km estimated range`
- `26 min · 10–80% DC fast charge`
- `34% recycled aluminum body content`
- `Bio-based cabin trims across primary touchpoints`

These should read as proof, not hype badges.

### 4. Sustainability & Materials Story

Create a section that explains the environmental thinking behind the vehicle.

Include content around:

- recycled and traceable materials
- low-emission production decisions
- interior fabrics, trims, or wood alternatives
- careful language that feels transparent and specific

Design this section with a premium materials editorial feel.

### 5. Performance / Charging Split Section

Create a split layout.

- one side: performance headline and a strong image or motion-oriented composition
- other side: concise specification blocks for acceleration, charging, thermal efficiency, and all-season confidence

The section should make it clear that sustainability did not come at the cost of performance.

### 6. Cabin Technology Section

Create a section focused on interior calm and driver experience.

Include:

- panoramic cabin imagery or premium interior framing
- software or interface highlights
- driver assistance cues
- sound insulation, comfort, and tactile materials

This should feel precise and desirable, not gadget-heavy.

### 7. Ownership Benefits Grid

Add a structured feature grid or benefits section.

Possible cards:

- home charging simplicity
- route-aware charging planning
- battery care warranty
- over-the-air updates
- service transparency
- lower running cost summary

Use concise copy and quiet icons only if needed.

### 8. Trust / Review Section

Add a refined testimonial or trust section.

- one large quote or two compact testimonials
- quiet attribution
- support with a short proof line such as awards, safety recognition, or ownership satisfaction

Avoid noisy logo-wall marketing.

### 9. Final CTA

End with a calm but persuasive CTA block.

- headline such as `See how responsible performance feels on the road`
- one short support line
- primary CTA: `Book a Drive`
- secondary CTA: `Download the Spec Sheet`

### 10. Footer

Create a minimal footer.

- brand mark and short positioning line
- grouped links for Vehicle, Sustainability, Ownership, Journal, Legal
- restrained visual treatment

## Design Details

Add only careful high-value details:

- thin frame lines
- subtle image masks
- spec labels in small uppercase text
- quiet section numbers such as `01`, `02`, `03`
- restrained hover cues
- balanced shadow depth

## Avoid List

Avoid all of the following:

- vague green claims with no evidence
- generic SaaS hero layouts
- overly dark cyberpunk styling
- giant icon grids
- crypto-like gradients
- aggressive neon accents
- heavy glassmorphism
- crowded comparison tables
- e-commerce clutter
- unrealistic sci-fi cockpit visuals

## Final Instruction

Create a coherent premium EV landing page that feels image-led, editorial, and technically credible. Make sustainability visible through proof, materials, and careful copy rather than empty marketing language. The final result should feel desirable first, then trustworthy, then informative.
